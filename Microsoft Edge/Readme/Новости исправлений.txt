   applyMasterVolume().

23. РЕАЛЬНЫЙ 0% MUTE ВСЕЙ ВКЛАДКИ

✅ Для случая, когда сторонние расширения/скрипты или дополнительные AudioContext
   воспроизводят звук в обход SoundForge, добавлен tab-level mute flow.

✅ Добавлен маршрут:
   inject.js
   → setTabVolumeMute
   → background.js
   → chrome.tabs.update({ muted: true/false })

✅ При 0%:
   • SoundForge Gain = 0
   • HardMuteNode = 0
   • FadeGain = 0
   • вкладка дополнительно переводится в muted state

✅ При возврате выше 0%:
   • исходное состояние вкладки восстанавливается

✅ При Disconnect:
   • исходное состояние mute вкладки восстанавливается

⚠️ Важно:
   tab-level mute является дополнительной защитой для сторонних источников звука
   и не заменяет основной SoundForge DSP mute.

→ Background

✅ Возникали лаги и сильная нагрузка.

ИСПРАВЛЕНИЕ:

✅ applyPreset — команда изменения Audio Engine.

✅ presetChanged — только событие синхронизации UI.

✅ presetChanged больше не должен повторно вызывать applyPreset.

→ 1 × SF_APPLY_PRESET
