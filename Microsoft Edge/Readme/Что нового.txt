12. ЕЩЁ БОЛЕЕ НАДЁЖНОЕ УПРАВЛЕНИЕ ГРОМКОСТЬЮ 🔊
───────────────────────────────────────────────────────────────────────────────

✅ Исправлен обходной native media path, из-за которого изменение громкости
   могло не влиять на весь слышимый сигнал.

✅ Пока SoundForge подключён, исходный <audio>/<video> остаётся muted,
   а звук проходит через единый Web Audio pipeline.

✅ Master Gain управляет итоговым обработанным сигналом.

✅ При Disconnect исходные volume и muted состояния восстанавливаются.

✅ Диапазон громкости:
   0% → полная тишина
   100% → базовый уровень
   200–800% → усиление

13. АБСОЛЮТНАЯ ТИШИНА ПРИ 0% 🔇
───────────────────────────────────────────────────────────────────────────────

✅ 0% теперь рассчитан не только на SoundForge GainNode.

✅ При необходимости используется дополнительный mute всей вкладки,
   чтобы блокировать звук сторонних AudioContext и других источников.

✅ Поддержан маршрут:
   inject.js
   → setTabVolumeMute
   → background.js
   → Chrome Tabs API

✅ При восстановлении громкости исходное состояние вкладки возвращается.

✅ Это особенно важно при одновременной работе с:
   • VOT
   • другими переводчиками
   • сторонними userscripts
   • дополнительными AudioContext

14. ОБНОВЛЁННАЯ АУДИО-ЦЕПОЧКА 🎚️
───────────────────────────────────────────────────────────────────────────────

Новая целевая DSP-архитектура:

↓

↓

↓
Dynamics Compressor
↓

↓

✅ Safety Limiter защищает итоговый output от чрезмерных пиков.

✅ Analyser располагается после обработки для более корректного отображения
   реально слышимого сигнала.

20. ИСПРАВЛЕНИЕ КРИТИЧЕСКОГО PRESET LOOP ♻️
───────────────────────────────────────────────────────────────────────────────

Была обнаружена важная регрессия при переходе на атомарную обработку пресетов.

Проблемный сценарий:

applyPreset
→ SF_APPLY_PRESET
→ presetChanged
→ applyPreset
→ SF_APPLY_PRESET
→ presetChanged
→ бесконечный цикл

Симптомы:

✅ Один пресет применялся много раз подряд.

✅ В консоли повторялось:
   "Применён пресет: logitech"

✅ Повторялось восстановление громкости.

✅ UI начинал сильно тормозить.

✅ Возникали рассинхронизации.

ИСПРАВЛЕНИЕ:

✅ applyPreset — только команда применения.

✅ presetChanged — только уведомление для синхронизации UI.

✅ presetChanged больше не запускает новый applyPreset.

Финальный поток:

1 × applyPreset
→ 1 × SF_APPLY_PRESET
→ 1 × Audio Engine update
→ 1 × presetChanged
→ UI synchronization
